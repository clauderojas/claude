# Acústica Gigante

Página interactiva (`index.html`, sin dependencias): una guitarra acústica gigante que se puede desmontar pieza por pieza, buscador e identificador de acordes sobre el diapasón, rasgueo con mouse/dedo/teclado y patrones de ritmo, y la lista de canciones de *La Ley MTV Unplugged* (2001) con los acordes por sección y tablaturas de cada posición (acordes según transcripciones de LaCuerda.net, sin letras), editables.

Abre `index.html` en el navegador. El sonido se sintetiza en vivo (Karplus-Strong).
