## Pasta Atelier

`pasta-atelier/index.html` — un bol de spaghetti en 3D (Three.js) al que se le agregan ingredientes.
Cada combinación muestra el nombre del plato (25 clásicos italianos + nombres de autor), su origen,
maridaje, calorías y macros, perfil de sabor, etiquetas de dieta y notas del chef.
Abrir el archivo en un navegador; no requiere build.
